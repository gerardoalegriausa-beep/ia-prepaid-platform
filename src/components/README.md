# Componentes React

- `ui/` — componentes generados por shadcn/ui (`npx shadcn@latest add ...`)
- `wallet/` — saldo, alertas de saldo bajo (< 50 cr), badges de costo
- `tools/` — formularios guiados y visores de salida por herramienta
- `merchant/` — banner co-branded
- `admin/` — tablas y formularios del panel
- `layout/` — header, footer, navegación
